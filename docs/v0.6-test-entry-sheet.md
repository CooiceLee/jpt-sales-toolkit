# JPT Sales Toolkit v0.6 测试入口说明

## 登录地址

请在公司局域网内访问：

```text
http://<测试服务器局域网IP>:8000
```

推荐使用 Chrome 或 Edge。

## 测试任务

请按自己的角色完成对应测试。

### Leader

1. 登录后查看 Dashboard 数字和地图。
2. 创建或导入一条新询盘。
3. 将 Lead 分配给一个 Sales。
4. 给同一条 Lead 添加 Watcher 或 Collaborator。
5. 检查不同账号是否只能看到自己应看到的数据。

### Sales

1. 查看自己负责的 Lead。
2. 新增一条 Follow-up。
3. 编辑刚新增的 Follow-up。
4. 填写 Deal 信息，例如报价号、PO 号、金额。
5. 上传并编辑一个测试附件。
6. 检查左侧数字、中间卡片、右侧详情是否同步刷新。

### Tech

1. 查看分配给自己的售前/售后任务。
2. 更新任务状态、问题描述或解决方案。
3. 检查是否看不到不属于自己的业务数据。

## 重点反馈内容

请重点反馈以下问题：

- 登录、切换页面、保存是否顺畅。
- 是否看到不该看到的数据。
- 保存后左侧数字、中间卡片、右侧详情是否一致。
- Follow-up、After-sales、Attachment 是否能创建、编辑、归档。
- 地图点位是否正确，手工定位是否好用。
- 哪些字段名称不符合实际业务表达。

## 注意事项

- 请不要录入敏感客户隐私或正式合同文件。
- 测试附件请使用无敏感内容的小文件。
- 不要共用账号。
- 如果页面无法打开，请确认电脑连接的是同一个局域网。
- 如果出现明显数据异常，请暂停操作并反馈。
