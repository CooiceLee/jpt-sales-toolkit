# JPT Sales Toolkit v0.7 数据复盘与出差规划需求

## 目标

v0.7 在 v0.6 试运行基础上补齐两个管理层能力：

1. 数据复盘：把已有 Lead、Activity、成交、售后和地图数据转成可执行的经营判断。
2. 出差规划：从 Review Map 和高价值 Lead 中挑选拜访对象，形成可保存、可回填、可导出的拜访计划。

本阶段不做复杂 CRM 自动化，不做实时路线优化，不接入机票酒店系统。

## 设计原则

- 数据复盘先只读，避免影响 v0.6 试运行数据。
- 出差规划复用现有客户坐标、阶段、金额、Owner、Activity，不重复建客户池。
- 地图坐标质量是前置条件；未确认坐标必须在计划中标记风险。
- 计划可以保存，但不改变 Lead 主状态；拜访结果以 Activity 回填。
- Leader 可看全局，Sales 只看自己负责或协作的数据。

## 数据复盘

### 需要回答的问题

- 哪些区域、国家、Owner、产品和应用场景带来更多有效机会？
- 哪些阶段存在堵点，例如长期 Assigned、Following 或 Quoted？
- 哪些高价值 Lead 长期没有跟进？
- 哪些丢单原因最集中？
- 哪些客户适合纳入下一次拜访计划？

### 筛选条件

- 时间范围：全部、本月、上月、本季度、自定义起止日期。
- 维度：Owner、Region、Country、Product Category、Application、Stage。
- 数据权限：遵循当前用户可见范围。

### 指标

- Lead 总数、新增数、Open 数、Won 数、Lost 数。
- Pipeline Value、Won Value、平均成交金额。
- Quote Rate、Win Rate、Loss Rate。
- 平均正式跟进次数、逾期跟进数、长期未跟进数。
- Top Region、Top Owner、Top Product、Top Application。

### 输出

- Summary Cards：核心指标。
- Review Brief：一段可复制的复盘摘要。
- Tables：阶段分布、Owner 表现、区域表现、风险 Lead、高价值 Open Lead、丢单原因。

## 出差规划

### 候选客户逻辑

系统按客户聚合 Lead，给出拜访优先级分数。分数用于排序，不替代人工判断。

加分项：

- Open Lead 数量多。
- Quoted / Following 阶段。
- Pipeline Value 或 Won Value 高。
- 有售后问题或复购可能。
- 同一城市或国家有多个客户。
- 最近有活动但尚未成交。

风险提示：

- 坐标为自动近似或国家级 fallback。
- 坐标缺失。
- 长期没有跟进。

### 计划创建

- 输入：计划名称、开始日期、结束日期、区域、Owner、说明。
- 可输入本轮出差起点、终点、默认交通方式、是否跳过周末、节假日日期。
- 从候选列表添加客户。
- 可为每个客户填写预计停留天数、拜访目的和备注。
- 可保存草稿。

### 行程生成

- 系统按起点、终点和已选客户坐标生成一条区域路线。
- 交通方式支持 `auto`、`drive`、`ground_public`、`flight`。当前版本为离线启发式估算，不调用实时交通、机票或酒店 API。
- 生成时会根据距离估算每段交通耗时和交通天数，并结合每个客户的停留天数生成计划开始日和结束日。
- 计划的结束日期会更新为本次生成路线后的计算结束日期。
- 可先预览路线不写库，确认后再保存路线。
- 日期计算默认跳过周末，可额外录入节假日日期；系统不会硬编码不同国家的官方假期，无效节假日输入会被忽略并返回 warning。
- 坐标缺失的客户不能参与自动行程生成，需要先补坐标或手动维护日期。
- 起终点经纬度会校验范围：纬度 `-90..90`，经度 `-180..180`。
- 停留天数限制为 `1..30` 天。

### 计划查看

- 显示客户、城市、国家、Lead 编号、Owner、阶段、金额、拜访目的、计划日期、备注。
- 地图高亮当前计划中的客户。
- 支持 Stop 上移/下移并持久化顺序。
- 生成行程后显示计算结束日期、工作日数、交通天数、总距离，并在地图上显示路线折线。

### 拜访结果回填

- 对计划中的单个 stop 记录结果：Planned、Visited、Follow-up Needed、Skipped。
- 填写拜访结果备注。
- 保存结果时同步写入对应 Lead Activity，action_type 使用 `comment`，summary 包含 `Trip visit` 前缀。

### 导出

- 支持导出 Markdown。
- 支持导出 CSV。
- 导出内容包含计划信息、拜访清单、坐标质量、Lead 摘要和备注。

## 数据表

新增两张轻量表：

```sql
trip_plans
trip_plan_stops
```

`trip_plans` 保存计划头信息，`trip_plan_stops` 保存客户/Lead 拜访项。删除采用归档，不硬删除。

## MVP 验收标准

- 数据复盘页面不修改业务数据，Leader 和 Sales 权限口径正确。
- 出差候选清单能按分数排序，并标记坐标质量。
- 可保存一个计划并添加、移除、重排客户。
- 可输入起点、终点、交通方式、节假日和停留天数后生成区域路线。
- 可记录拜访结果，并在 Lead Activity 中看到回填记录。
- Markdown 和 CSV 导出可下载并包含完整计划清单。
