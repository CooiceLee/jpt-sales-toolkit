# JPT Sales Toolkit 0.11.4-internal 本地候选验证结果

验证日期：2026-07-20
状态：源码全量回归、真实数据隔离浏览器验收及本机 macOS Intel 安装包烟测通过；Git 提交和跨平台构建待完成。

## 稳定业务口径

- 业务地区按 Lead 负责人账号划分，固定为 `GLOBAL / 欧洲 / 北美/加拿大/澳洲 / 俄罗斯/土耳其/中东 / 东南亚`。`GLOBAL` 是真实业务归属，不等于“全部地区”。
- “已逾期 / 今日到期 / 未来 7 天”只判断下一次计划跟进日期；长期未跟进按“最近正式跟进 → 询盘日期 → 创建日期”回退计算。
- “售前 / 样品管理”只展示存在有效 `pre_sales_tasks` 的商机，不把全部 `Following` 商机误判为样品任务。
- 客户名称与别名只用于生成模糊候选；Leader 必须选择来源和保留目标、检查只读迁移预览后，才能执行一次合并。
- 地图把坐标分为精确、自动近似、国家聚合与缺失。国家聚合点不是客户精确位置；没有坐标的客户仍保留在列表和坐标治理队列。

## 本轮完成

- 五类负责人业务地区已接入各销售工作台，并与负责人、技术、搜索、阶段及权限条件取交集。新建成员和首次 Leader 建号必须选择地区，历史空地区记录仍可读取。
- 跟进页增加“从未正式跟进”、7/14/30/60/90 天和自定义日期范围；卡片显示最近正式跟进、未活动时长和下一次计划日期。
- 跟进工作台显式读取最多 100000 条，避免超过 1000 条时漏掉最老记录；地图跳转卡片时会清除旧业务地区条件。
- 空页面会区分“全部记录缺计划日期”“组合筛选无结果”“计划与活动条件无交集”和“自定义日期范围无效”。
- 客户模糊搜索覆盖主名称和有效别名，显示匹配分数与匹配来源；快速连续搜索使用请求序号防止旧结果覆盖新结果。
- 合并预览逐项显示字段、源值、目标值和处理方式；确认按钮只在来源、目标和两个 `row_version` 与成功预览完全一致时可用。
- Excel 重导仅会自动收敛内容完全等价且没有独立更新历史的重复售前任务；发现 App 手工差异、非法 JSON 或独立任务活动时，预检会阻断并要求人工复核，安全收敛会校验 `row_version` 并写入审计记录。
- 地图拒绝 `null`、空字符串、越界和非数值坐标；Trip Planner 遇到缺坐标客户会跳过点位而不再触发 Leaflet 崩溃。
- 国家级回退客户按国家聚合为一个标记，地图显示坐标质量图例、缺失数量及离线/底图失败状态；窄屏 Trip Planner 改为单列布局。
- Sampling/Excel 字段同步、双连接并发幂等、损坏 JSON 防覆盖、详情字段完整显示和中文枚举翻译保留通过。
