# 团队试运行检查表

每个平台至少安排一名真实角色成员完成：

- [ ] 一键安装并启动，浏览器只访问本机 `127.0.0.1`。
- [ ] Leader 首次初始化并保存签发器口令和完整备份。
- [ ] 创建 Sales、Tech，完成 `.jptreq → .jptauth → 验证码 → 登录`。
- [ ] 同一成员换机重签后，旧授权记录变为历史。
- [ ] Sales 只能查看自己负责/协作的客户和 Lead。
- [ ] Tech 只能查看自己的任务及关联数据，且看不到销售敏感字段。
- [ ] 错设备、错验证码、篡改文件和 91 天授权均被拒绝。
- [ ] Leader 续期和“登录密码 + 签发器口令”恢复均成功。
- [ ] 备份恢复后数据库、附件和授权配置一致。
- [ ] 无网络时除在线地图底图/地址服务外的核心流程仍可用。
- [ ] 从用户菜单执行 `Exit JPT` 后覆盖升级；升级不丢数据，卸载默认保留数据目录。

反馈格式：平台与版本、成员角色、复现步骤、预期结果、实际结果、截图/日志路径、是否阻塞核心流程。
