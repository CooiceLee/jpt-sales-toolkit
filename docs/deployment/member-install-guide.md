# Windows / macOS 成员安装指南

适用版本：`v0.11.7-internal`。

## 安装前准备

向 Leader 获取与你电脑架构对应的内部测试安装包：

- Windows 10/11 x64：`Windows-x64-...-Setup.exe`
- Apple Silicon Mac：`macOS-AppleSilicon-arm64-...dmg`
- Intel Mac：`macOS-Intel-x86_64-...dmg`

当前产物明确标记 `UNSIGNED-INTERNAL`，只用于团队内部试运行。Windows SmartScreen 或 macOS Gatekeeper 可能要求手动确认；正式无阻碍分发仍需公司代码签名证书和 Apple Developer ID/notarization。

Linux 不在产品支持和发布范围内。安装包不包含业务 Excel、标准模板、成员账号、`.jptauth` 或测试数据；这些内容必须在程序安装和基础功能验收后分别取得。

## 安装与激活

1. 安装并启动 JPT Sales Toolkit。Windows 从开始菜单启动；macOS 必须先把 App 拖入“应用程序”、推出 DMG，再从“应用程序”启动，不能直接运行 DMG 内的 App。
2. 已有团队成员选择“Join an Existing Team”。
3. 下载 `.jptreq`，发送给 Leader。
4. 收到 `.jptauth` 后，同时从另一条可信渠道取得 16 位 Leader verification code。
5. 导入 `.jptauth`、输入验证码并设置至少 8 位的本地登录密码。
6. 使用页面自动填入的成员用户名登录。

文件或验证码错误、设备不匹配、授权被篡改或已经到期时，激活会整体失败，不会留下部分账号或半授权数据。

macOS 详细安装顺序：

1. 退出旧版 JPT，并关闭旧的 `127.0.0.1` 浏览器页签。
2. 打开与芯片架构匹配的 DMG。
3. 把 `JPT Sales Toolkit.app` 拖入 `Applications / 应用程序`；覆盖升级时选择替换。
4. 在 Finder 侧边栏推出该 DMG。
5. 进入 Finder 的“应用程序”，从这里打开 JPT。新版如果检测到仍从 DMG 运行，会在页面顶部显示安装位置警告。

完成激活后，先创建一条可识别的测试记录，退出并重新启动程序，确认记录仍在。只有程序安装、登录、退出、重启和本地数据保存全部通过后，才进入 Excel 导入、权限映射或数据包同步测试。

## 本地数据位置

- Windows：`%LOCALAPPDATA%\JPT Sales Toolkit\data`
- macOS：`~/Library/Application Support/JPT Sales Toolkit/data`

覆盖升级前先从左下角用户菜单选择 `Exit JPT`，确认后台程序已经退出，再运行新安装包或替换 `.app`。升级只替换程序，不覆盖该目录；卸载默认保留业务数据、附件、备份和授权。删除本地数据必须另行人工确认。

新版第一次打开旧数据时，会先在上述数据目录的 `backups` 子目录创建 `pre_upgrade_...zip`，校验数据库、附件和授权配置后才迁移。迁移失败时程序不会进入业务页面，而会自动恢复原数据库。此时不要删除数据目录或反复安装；保留提示截图和 `data/logs/launcher.log`，交给 Leader 或管理员处理。管理员手动恢复时只能选择系统自动生成且清单类型为 `pre_upgrade` 的 ZIP；普通完整备份不能走该数据库专用入口。正式替换前，程序还会保存并校验当前数据库为 `backups/pre_recovery_current_*.sqlite`，这一步失败则不会恢复。

升级验收必须完成四项核对：原账号可登录、升级前客户/询盘数量一致、至少打开一个原附件、完全退出并第二次启动后数据仍一致。出现任一差异时停止继续录入新数据。

因此，升级后不会重新要求创建 Leader 或重新导入授权，这是正常的数据保留行为，不代表缓存没有刷新。若升级后仍看到旧界面，先确认没有从 DMG 或旧程序副本启动，再关闭旧浏览器页签并从新版程序重新打开；不要删除数据目录来刷新界面。

## 无网络行为

登录、设备授权、客户和销售漏斗等核心功能可离线启动。地图程序本身已随应用打包，但在线底图、地址解析和地图瓦片仍需要网络。地址搜索和批量地理编码会把填写的地址、城市、邮编和国家通过 HTTPS 发送给一个或多个外部地理编码服务；默认使用公共 Nominatim。若管理员启用高德，部分可回退故障会继续查询 Nominatim，界面会显示实际返回候选的服务商。高德只负责可选地理编码，不替换 CARTO/OpenStreetMap 底图；打开地图也会向瓦片服务发送网络地址和当前视窗/瓦片坐标。普通成员不要自行配置或索取高德 Key；禁止外发的客户地址不要使用地址搜索，应改用人工经纬度或地图选点。无网或底图加载失败时页面会给出提示；客户列表、业务地区筛选、坐标质量状态和人工修正不依赖底图继续可用。

## 首次业务核对

1. 在页面右上角确认版本为 `v0.11.7-internal`。
2. 在中英文间切换一次，确认布局不下移且当前模块仍保持。
3. 打开跟进管理：`已逾期 / 今日到期 / 未来 7 天` 按计划日期显示；长期未跟进条件按实际活动时间计算，两类条件不要混为一谈。
4. 核对自己的业务地区。可选值只有 `GLOBAL / 欧洲 / 北美/加拿大/澳洲 / 俄罗斯/土耳其/中东 / 东南亚`；`GLOBAL` 不等于“全部地区”。
5. 地图上的近似位置只用于区域参考；涉及拜访或路线时，应先确认精确地址或人工坐标。
6. 卡片不按客户名称统一排序：处理页优先最早询盘；跟进页优先最近计划日期；售前/样品、成交、履约和售后按各自阶段与业务日期排序。刷新后同一组卡片顺序应保持稳定。
7. Sales 收到 Leader 的 JSON 包时，先确认 Leader 已在导出页选择本人账号。定向包只含本人作为负责人的 Lead；若页面提示接收账号不匹配，停止导入并向 Leader 索取正确文件。
