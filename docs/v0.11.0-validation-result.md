## 3. 模块化试运行 Gate

- Gate A：程序安装、设备申请、授权激活、基础增删改查、退出重启、备份恢复。
- Gate B：独立 Excel 预检、人工修正、提交、重复导入、更新导入和回滚。
- Gate C：成员名称映射实际账号，验证 Leader/Sales/Tech 的数据归属和权限边界。
- Gate D：JSON 数据包的导出、传递、预检、导入、幂等、权限和异常恢复。

Gate A 必须先在团队真实 Windows/macOS 设备上通过，之后才能依次放行 B、C、D。自动化通过不替代真实设备和真实成员角色试运行。
