## 验证中发现并修复的问题

| 问题 | 修复 |
|---|---|
| `test_contact_validation.py` 的 `main()` 没有向前两个测试传入 `ids`，导致统一验证脚本中断。 | 测试入口现在为前两个测试创建测试库并传入 `ids`，重建测试库前显式 `close_db()`。 |
| email-only 联系人符合业务校验，但数据库 `customer_contacts.name` 为 `NOT NULL`，会触发写库失败。 | `CustomerService` 写入前会把 email-only 联系人的 `name` 自动填为 email，并统一清理 name/email 空白。 |
| 当前 Python 环境缺少 `httpx`，导致 FastAPI `TestClient` 无法运行。 | `requirements.txt` 已包含 `httpx`，本机已按 `python3 -m pip install -r requirements.txt` 安装依赖后完成验证。 |
